# Pallet3D-Stability: Pallet_Stability_Benchmark_Dataset
This repository contains a dataset containing 13k different pallet layouts (ranging from 20 - 60 items sampled from a common catalog of 600 items) including stability labels. It also contains the code that was used to generate this dataset.



## Dataset format 

Each transport unit is stored as a JSON object containing its item configuration and the corresponding stability information generated by the MSC Adams simulation. The following example illustrates the dataset structure:

```json
{
    "id": 0,
    "item_count": 52,
    "items": [
        {
            "lx": 1038,
            "ly": 0,
            "lz": 190,
            "rx": 1176,
            "ry": 205,
            "rz": 330,
            "id": 9,
            "weight": 1442
        },
        ...
    ],
    "movement_values_adams_fall": {
        "mean_x_movements/mm": "6.9",
        "max_x_movements/mm": "42.98",
        "mean_y_movements/mm": "8.4",
        "max_y_movements/mm": "116.6",
        "mean_z_movements/mm": "13.4",
        "max_z_movements/mm": "30.8",
        "is_stable": "False",
        "item_translations": [
            {
                "item_name": 9,
                "itemDelta": 11.2,
                "x_movement": 7.8,
                "y_movement": 32.5,
                "z_movement": 17.6
            },
            ...
        ]
    }
}
```

The Dataset in "Datset" addtionally carries all additional stability estimations from Blender, KPIs and VPS-ResNet in analog format.

## Benchmark KPIs

The following KPIs are based on the indicators proposed by [Poolavaram et al.]([LINK-TO-PAPER](https://arxiv.org/abs/2601.11325)) and were adapted for the benchmark.

| KPI | Description |
| --- | --- |
| **Absolute Density** | Measures space utilization of the transport unit (TU) by comparing the total volume of all items to the bin volume. |
| **Relative Density** | Measures space utilization of the TU by comparing the total volume of packed items to the volume of the utilized space. |
| **Center of Gravity 2D** | Measures how close the actual center of gravity (CoG) is to the ideal CoG in 2D space. The ideal CoG is located at the center of the TU. |
| **Center of Gravity 3D** | Measures how close the actual CoG is to the ideal CoG in 3D space. The ideal CoG is located at the center of the TU. |
| **Side Support** | Measures how many lateral sides of each item are supported by neighboring items and relates the number of supported sides to the total number of sides. |
| **Side Support (adjusted)** | Extends Side Support by treating outward-facing sides of items at the boundary of the TU as fully supported, since these sides cannot be supported by another item. |
| **Surface Support** | Measures the fraction of each item's base area supported by underlying items or the pallet and calculates the average across all items. |
| **Surface Support (adjusted)** | Extends Surface Support by combining the average surface support with the minimum surface support observed among all items on the TU. |
| **Height-Width Ratio** | Penalizes large items for being placed at greater heights on the TU. |
| **Pillar Score** | Identifies tall freestanding structures on the TU, with larger structures receiving a higher penalty. |
| **Overall Stability Score** | Weighted combination of the individual KPIs proposed by the original authors. While the original implementation used randomly assigned weights, the benchmark implementation determines the weights using logistic  regression. |

## ResNet Configuration

### Model Architecture

| Parameter                | Configuration                   | Description                                                                    |
| ------------------------ | ------------------------------- | ------------------------------------------------------------------------------ |
| Model type               | 3D ResNet                       | Residual CNN operating on voxelized pallet representations                     |
| ResNet depth             | ResNet-34 style                 | Uses block configuration `(3, 4, 6, 3)`                                        |
| Residual block           | `BasicBlock3D`                  | Two `3×3×3` convolutions with residual/skip connection                         |
| Bottleneck expansion     | `1`                             | `BasicBlock3D.expansion = 1`                                                   |
| Input channels           | `1`                             | Single voxel-information channel in current baseline                           |
| Initial feature channels | `32`                            | Number of feature maps produced by the stem                                    |
| Initial convolution      | `Conv3d(1, 32)`                 | First convolutional layer                                                      |
| Initial kernel size      | `5×5×5`                         | `kernel_size=5`                                                                |
| Initial stride           | `1`                             | No spatial reduction in first convolution                                      |
| Initial padding          | `2`                             | Preserves spatial dimensions through initial convolution                       |
| Initial convolution bias | `False`                         | Bias omitted because BatchNorm follows                                         |
| Stem normalization       | `BatchNorm3d(32)`               | Normalizes initial feature channels                                            |
| Activation               | ReLU                            | `ReLU(inplace=True)`                                                           |
| Initial pooling          | `MaxPool3d(3×3×3)`              | `kernel_size=3`, `stride=2`, `padding=1`                                       |
| Layer 1                  | 3 residual blocks, 64 channels  | First ResNet stage                                                             |
| Layer 2                  | 4 residual blocks, 128 channels | Second ResNet stage                                                            |
| Layer 3                  | 6 residual blocks, 256 channels | Third ResNet stage                                                             |
| Layer 4                  | 3 residual blocks, 512 channels | Fourth ResNet stage                                                            |
| Residual convolution     | `3×3×3`                         | Padding `1`, bias disabled                                                     |
| Skip projection          | `1×1×1 Conv3d`                  | Used when stride or channel count changes                                      |
| Residual normalization   | `BatchNorm3d`                   | Applied after convolutions and skip projections                                |
| Global pooling           | `AdaptiveAvgPool3d(1,1,1)`      | Reduces final spatial representation to one value per feature channel          |
| Final feature size       | `512`                           | Using `BasicBlock3D` with expansion `1`                                        |
| Output layer             | `Linear(512, 1)`                | Produces one raw binary-classification logit                                   |
| Output activation        | None                            | Sigmoid is not applied inside the model because `BCEWithLogitsLoss` handles it |

### Training Configuration

| Hyperparameter             |                                   Value | Description                                                                               |
| -------------------------- | --------------------------------------: | ----------------------------------------------------------------------------------------- |
| Task                       |                   Binary classification | Stable vs. unstable pallet                                                                |
| Loss function              |                     `BCEWithLogitsLoss` | Binary cross-entropy applied directly to logits                                           |
| Optimizer                  |                                   AdamW | Adaptive optimizer with decoupled weight decay                                            |
| Initial learning rate      |                                 `0.001` | `1e-3`                                                                                    |
| Weight decay               |                                `0.0001` | `1e-4`                                                                                    |
| LR scheduler               |                     `ReduceLROnPlateau` | Reduces learning rate when validation loss stops improving                                |
| Scheduler mode             |                                   `min` | Lower validation loss is considered better                                                |
| Scheduler factor           |                                   `0.5` | Learning rate is halved after a plateau                                                   |
| Scheduler patience         |                              `3 epochs` | Number of non-improving epochs before reducing LR                                         |
| Maximum epochs             |                                   `100` | Upper limit; early stopping/checkpoint selection can terminate effective training earlier |
| Training batch size        |                                     `8` | Current high-resolution/on-the-fly configuration                                          |
| Training shuffle           |                                  `True` | Training samples randomized each epoch                                                    |
| Validation shuffle         |                                 `False` | Deterministic validation iteration                                                        |
| Test shuffle               |                                 `False` | Deterministic test iteration                                                              |
| DataLoader workers         |                                     `0` | Avoids concurrent creation of large voxel grids                                           |
| Gradient reset             | `optimizer.zero_grad(set_to_none=True)` | More memory-efficient gradient clearing                                                   |
| Model checkpoint criterion |                           Validation F1 | Best-performing validation model is saved                                                 |
| Scheduler criterion        |                         Validation loss | Scheduler operates independently of F1 checkpoint selection                               |

### Input / Voxel Configuration

| Parameter                       | Configuration                     | Description                                                              |
| ------------------------------- | --------------------------------- | ------------------------------------------------------------------------ |
| Physical pallet space           | `1200 × 2000 × 800`               | Input-space dimensions used by the voxelizer                             |
| Input representation            | Dense 3D voxel grid               | Created from pallet item geometry                                        |
| Current input channels          | `1`                               | Current baseline uses a single encoded voxel channel                     |
| Downsampling                    | Configurable                      | Raw geometry coordinates are mapped into a lower-resolution voxel space  |
| Box representation              | `(lx, ly, lz)` → `(rx, ry, rz)`   | Lower-front-left and upper-back-right coordinates                        |
| Coordinate conversion           | Floor lower edge, ceil upper edge | Preserves item extent during voxelization                                |
| Current geometry encoding       | Interior + borders                | Typical encoding: empty `0.0`, item interior `0.5`, item boundary `1.0`  |
| Dataset size                    | `13,485` pallets                  | Individual pallet descriptions stored as separate JSON files             |
| Train / validation / test split | `80 / 10 / 10 %`                  | Created using `random_split`                                             |
| Split seed                      | `42`                              | Used for reproducible dataset partitions                                 |
| Voxel generation                | On-the-fly                        | Voxel tensors are generated during dataset access instead of precomputed |

### Validation / Evaluation Metrics

| Metric                           | Meaning                                                                                                     |                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Validation BCE loss              | Measures probabilistic classification error on unseen validation data                                       |                                                     |
| Accuracy                         | Fraction of all pallets classified correctly                                                                |                                                     |
| Precision                        | Fraction of predicted stable pallets that are actually stable                                               |                                                     |
| Recall / Sensitivity             | Fraction of actually stable pallets correctly identified                                                    |                                                     |
| Specificity                      | Fraction of actually unstable pallets correctly identified                                                  |                                                     |
| F1 score                         | Harmonic mean of precision and recall                                                                       |                                                     |
| ROC-AUC                          | Measures the model's ability to rank stable pallets above unstable pallets independent of a fixed threshold |                                                     |
| PR-AUC                           | Area under the precision-recall curve                                                                       |                                                     |
| Default classification threshold | `0.5`                                                                                                       |                                                     |
| Validation threshold search      | `0.05–0.95` in steps of `0.05`                                                                              | Used to find the validation threshold maximizing F1 |
| Confusion matrix values          | TP, TN, FP, FN                                                                                              | Used to calculate classification metrics            |
